# Security policy

MergeShield is an early MVP and is not intended to be a production release gate.

## Reporting a vulnerability

Do not publish confidential API specifications, access tokens, or credentials in public issues. For a private deployment, report suspected vulnerabilities to the repository maintainer through a private channel and include reproducible steps without sharing sensitive production data.

## Current data handling

The MVP is stateless and does not intentionally persist submitted specifications. Do not upload confidential specifications to a public deployment until access controls, request limits, logging, and data-handling behavior have been reviewed. This note is not a substitute for a security audit.
